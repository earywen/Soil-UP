# Rédaction de pré-synthèses analytiques assistée par LLM

L'ingénieur a besoin non seulement de données brutes consolidées mais aussi d'une première analyse textuelle de sensibilité environnementale pour son offre ou son rapport. Nous intégrons un composant de synthèse par modèle de langage (LLM) qui interprète les données collectées (distance aux sites BASIAS, absence/présence de captages AEP, nature géologique) pour formuler des paragraphes de synthèse et de pré-diagnostic directement éditables dans le document Word.
